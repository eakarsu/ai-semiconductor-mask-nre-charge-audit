# Semiconductor Mask & NRE Charge Audit

Validate mask, tape-out, engineering, and nonrecurring charges against milestones, ownership, respin responsibility, and waivers.

**Primary buyer:** Fabless semiconductor companies and OEMs. **Evidence:** foundry agreements, tape-outs, mask sets, engineering lots, NRE milestones, respins, ownership, waivers, invoices, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Foundry agreement library
- Tape-out program registry
- Mask set inventory
- Layer count validation
- NRE milestone tracking
- Engineering lot calculation
- Respins responsibility
- Design change attribution
- Waiver credit control
- Tooling ownership evidence
- Invoice matching
- Duplicate NRE detection
- Foundry dispute workflow
- Credit reconciliation
- Program node analytics

Run `./start.sh`, then open <http://127.0.0.1:4705>. API: `5705`.
